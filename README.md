# ISO-TEI-Spoken: Tool Support

The project **Transcription+** (https://transcription-plus.awhamburg.de/) is revising, consolidating and publishing resources related to the ISO standard 
**ISO 24624:2016 Language resource management — Transcription of spoken language** (https://www.iso.org/standard/37338.html).

This repository gathers existing resources from different existing resources and makes them available as a library / API.

To use this library as a maven dependency, do this:

```
 <repository>
   <id>github</id>
   <url>https://maven.pkg.github.com/zumult-org/spotei</url>
 </repository>                  

<dependency>
  <groupId>de.linguistibits</groupId>
  <artifactId>spotei</artifactId>
  <version>0.0.2</version>
</dependency>
```
